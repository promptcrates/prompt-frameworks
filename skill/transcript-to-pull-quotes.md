# Transcript → pull quotes — Trigger · Input · Output

Related guide: https://promptcrates.com/guides/interview-transcript-into-pull-quotes

```
TRIGGER:
You have an interview transcript and need short pull quotes for an article.

INPUT:
Paste the transcript only. Do not add biography or imagined context.

OUTPUT:
A list of verbatim quotes, each ≤ 25 words.
Ban paraphrase. Ban invented lines.
If a line is unclear in the source, mark it UNCLEAR instead of fixing it.
```

This is a Skill: a reusable work instruction, not a one-shot "write me quotes" prompt.
